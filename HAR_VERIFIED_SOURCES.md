# V16 verified-source notes

Key platform families include Workday, Oracle HCM, Phenom, SuccessFactors/jobs2web, Jibe/iCIMS-style APIs, Crelate, Sitecore Discover, Samsung search, Avature-style portals, CSOD, Greenhouse, Lever, and Ashby.
